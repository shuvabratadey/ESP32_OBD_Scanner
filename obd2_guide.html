01 What is OBD2?

OBD2 (On-Board Diagnostics, Version 2) is a standardized system built into all cars (1996+) and most motorcycles (2003+) that exposes the vehicle's internal sensors, ECU data, and diagnostic trouble codes (DTCs) through a standard 16-pin connector.

The ELM327 chip acts as a translator between the vehicle's proprietary protocol (CAN, ISO, VPW, PWM) and a simple human-readable AT command interface over Bluetooth serial.

[Your Laptop] ←─ Bluetooth Serial ─→ [ELM327 Mini] ←─ OBD2 Wire ─→ [Vehicle ECU]
⚠ Clone Warning: Most "Mini" ELM327 adapters sold cheaply are clones of the original chip. They work for basic OBD2 reading but may report firmware version incorrectly, have limited AT command support, fail on some advanced CAN protocols, or drop connections intermittently.

03 CAN Bus Protocol Explained

CAN (Controller Area Network) is the most common modern vehicle protocol. Understanding it helps decode raw OBD2 responses.

CAN Frame Structure

┌────────┬──────────┬──────┬───────────────────────┬─────┐
│  SOF   │  CAN ID  │  DLC │        Data           │ CRC │
│ 1 bit  │ 11 bits  │ 4bit │   Up to 8 bytes       │     │
└────────┴──────────┴──────┴───────────────────────┴─────┘

OBD2 CAN IDs (Standard 11-bit)

CAN IDDirectionDescription
0x7DFTester → ECUFunctional broadcast (all ECUs listen)
0x7E0Tester → ECU 1Physical address to Engine ECU
0x7E8ECU 1 → TesterResponse from Engine ECU
0x7E1Tester → ECU 2Transmission ECU
0x7E9ECU 2 → TesterResponse from Transmission ECU

OBD2 CAN Message Example — Send 010D (Vehicle Speed)

// REQUEST  (Tester → ECU via 0x7DF)
Byte 0: 02           = 2 data bytes follow
Byte 1: 01           = Mode 01 (current data)
Byte 2: 0D           = PID 0x0D (vehicle speed)
Bytes 3-7: 00 00 00 00 00  (padding)

// RESPONSE (ECU → Tester via 0x7E8)
Byte 0: 03           = 3 data bytes follow
Byte 1: 41           = 0x40 + Mode (0x01) = positive response
Byte 2: 0D           = PID echoed back
Byte 3: XX           = Actual speed value in km/h

05 Setting Up Serial Debug Assistant

Step 1 — Pair the ELM327 via Bluetooth

  1. Plug the ELM327 Mini into the vehicle OBD2 port (ignition ON)
  2. Red LED on adapter should illuminate
  3. Windows: Settings → Bluetooth & devices → Add device
  4. Look for OBDII, ELM327, or V-LINK
  5. Enter pairing PIN: 1234 (or try 0000)
  6. A virtual COM port is created — note it (e.g., COM4, COM5)

Step 2 — Find the COM Port

Right-click Start → Device Manager → Ports (COM & LPT)

  Standard Serial over Bluetooth link (COM4)   ← Use this (outgoing)
  Standard Serial over Bluetooth link (COM5)   ← Incoming (ignore)

Step 3 — Serial Debug Assistant Settings

SettingValue

Baud Rate38400
Data Bits8

Line Ending\r (Carriage Return only)
Critical: ELM327 uses Carriage Return \r as command terminator — NOT newline \n. Ensure your Serial Debug Assistant appends only \r to each sent command.

07 OBD2 PID Commands

A command like 010C breaks down as: Mode 01 + PID 0C. The ECU replies with mode + 0x40:

Request:   01 0C      → Mode 01, PID 0C (Engine RPM)
Response:  41 0C 1A F8  → Positive response, data bytes follow
           ── ── ───────
           41 = 0x40 + mode 0x01 (positive response)
           0C = PID echoed
           1A F8 = actual data bytes A, B

Service Modes Overview

01Live / current data010CReal-time ECU values (RPM, speed, temp…)
02Freeze frame data020CSnapshot captured when fault occurred
03Read stored DTCs03Trouble codes in ECU memory
04Clear DTCs + reset monitors04Clears codes and readiness data
07Read pending DTCs07Faults not yet matured into stored codes

08 Decoding Responses

Response Anatomy (Headers ON — ATH1)

7E8  03  41  0D  3C
 │    │   │   │   └── Data byte A = 0x3C = 60 decimal
 │    │   │   └─────── PID echoed (0x0D = Vehicle Speed)
 │    │   └─────────── Response mode (0x41 = 0x40 + Mode 01)
 │    └─────────────── Number of following data bytes (3)
 └──────────────────── CAN ID of responding ECU (0x7E8 = Engine ECU)

Example 1 — Engine RPM 010C

7E8→Engine ECU responding
04→4 data bytes follow
41→Mode 01 positive response
0C→PID = RPM confirmed
1A F8→A = 0x1A = 26, B = 0xF8 = 248
Formula: RPM = (256 × A + B) / 4
       = (256 × 26 + 248) / 4
       = 6904 / 4
       = 1726 RPM

Example 2 — Vehicle Speed 010D

Response: 7E8 03 41 0D 3C
Formula:  Speed = A = 0x3C = 60 decimal = 60 km/h

Example 3 — Coolant Temperature 0105

Response: 7E8 03 41 05 7B
Formula:  Temp = A − 40 = 123 − 40 = 83°C

Example 4 — Throttle Position 0111

Response: 7E8 03 41 11 64
Formula:  Throttle = A × 100 / 255 = 100 × 100 / 255 = 39.2%

DTC Decoding (Mode 03)

Response: 43 02 03 00 01 30
          ── ──
          43 = Mode 03 response
          02 = 2 DTCs stored

DTC byte pair: Hi=0x03, Lo=0x00
  Top 2 bits of Hi (00) → P (Powertrain)
  → P0300 — Random/Multiple Cylinder Misfire

Prefix table:
  0x0X = P0  (Powertrain, generic)
  0x4X = C0  (Chassis)
  0x8X = B0  (Body)
  0xCX = U0  (Network)
